# v0.62 战斗目标锁定与攻击预演

## 版本号与分配依据

- 版本号：v0.62。
- 依据：v0.61 已完成 AI 击杀候选分层和移动集火协同；按其遗留事项进入下一轮战斗 UI 目标锁定与攻击预演。

## 背景

当前地图攻击徽标和命令坞攻击按钮直接调用 `GameViewModel.attack`，会立即改变 `GameState`。多目标时命令坞固定取 `attackTargets.first`，玩家看不到目标选择和完整的同源 `CombatPreview`。核心已有 `GameState.attackPreview`，应把它提升为明确的“锁定 -> 预演 -> 确认”交互。

## 本轮目标

1. 在 `GameViewModel` 增加不写入 `GameState` 的 `selectedAttackTargetID`，派生 `SelectedCombatForecast`，展示伤害、反击、双方剩余生命、支援/包夹/指挥/守援修正和预计结果。
2. 地图攻击徽标改为真正的 SwiftUI `Button`：点击只锁定目标、聚焦目标并显示焦点环；确认命令才调用既有 `attack` 结算。
3. 命令坞无锁定目标时用 `Menu` 列出全部可攻击目标，有锁定目标时显示确认/歼灭命令；抽屉攻击列表和地图入口必须调用同一 `focusAttackTarget`。
4. 保持 `CombatPreview` 与实际 `GameState.attack` 同源，锁定/查看预演不得改变单位、城市、资源、回合或阵营。
5. RenderBattlePreview 增加相邻敌军 fixture，断言锁定前后核心状态不变、`SelectedCombatForecast.preview == state.attackPreview`，并在单位场景渲染后清除锁定再进入城市场景。

## 非目标

- 不修改 `Sources/RomeLegionsCore/GameState.swift` 的战斗公式、伤害、反击或存档结构。
- 不改变 AI、敌军静态意图、地图镜头数学、将领规则或外交规则。
- 不引入第三方框架、跨平台技术栈或全局 Observation 迁移。
- 不在 SwiftUI body 中新增战斗评分；视图只展示 ViewModel 派生字段并触发命令。

## 当前架构依据

- `GameState.attackPreview(attackerID:defenderID:)` 是唯一预演来源，`GameState.attack(attackerID:defenderID:)` 继续复用同一公式。
- `GameViewModel` 持有选择态和命令态；`GameViewModelSelectionReadouts.swift` 承载 `SelectedCombatForecast`。
- `BattleMapView.swift` 承载地图空间层和攻击入口；`BattleShellControls.swift` 承载底部命令坞；`BattlePanels.swift` 承载抽屉读板。
- `MapViewportState` 只负责镜头，不得把攻击锁定写入存档或玩法状态。

## 实现步骤

1. 清理所有攻击入口的状态流：目标按钮/抽屉按钮调用 `focusAttackTarget`，唯一确认入口调用 `confirmSelectedAttack`，低层 `attack(_:)` 负责结算后清除锁定。
2. 为锁定目标提供紧凑和完整两种读板，保证 Dynamic Type、44pt 点击区域、VoiceOver 标签和不依赖颜色的焦点环。
3. 命令坞目标菜单展示每个目标的伤害/反击摘要；锁定后显示确认/歼灭按钮，并在身份区保留紧凑预演摘要。
4. RenderBattlePreview 在单位场景前锁定 fixture，断言只读状态不变和预演同源；渲染后清除锁定，继续既有城市读板断言。
5. 更新结构门禁、CI 版本、README、flow、flowchart、test、prompt README 和后续正式日志；保留用户已有 Xcode 与 Unity 分析未提交改动。

## 验收标准

- 地图/抽屉/命令坞点击攻击目标只锁定，不改变 `GameState`；确认按钮才结算。
- 多目标不再隐式使用 `.first`；菜单列出全部合法目标，锁定目标有金白焦点环和 VoiceOver 预演标签。
- `SelectedCombatForecast` 的字段和 UI 文案来自同一个 `CombatPreview`，包含伤害、反击、双方剩余生命、修正和歼灭/高风险结果。
- RenderBattlePreview 的只读锁定断言、单位场景和既有城市场景全部通过，六图无重叠、裁切或空白回退。
- 文档、结构门禁、CI manifest 版本为 v0.62，并在云端结果包通过后再写正式验收记录。

## 风险与禁止项

- 禁止在地图或按钮闭包中重新计算伤害；禁止让预演和结算走两套公式。
- 禁止锁定状态进入 `GameState`、Codable、SaveStore 或 AI 意图预测。
- 禁止保留任何用户可见的攻击入口绕过锁定确认；禁止以 `.first` 隐藏多目标。
- 禁止触碰或暂存用户未提交的 `project.pbxproj`、`xcuserstate` 和 `md/unity分析/`。
