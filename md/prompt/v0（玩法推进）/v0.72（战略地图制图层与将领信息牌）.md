# v0.72 战略地图制图层与将领信息牌

## 版本与范围

- 版本号承接 v0.71，为 v0.72；依据是 `update_log.md` 当前最新实现轮次。
- 本轮属于 Agent X 单人推进，用户明确要求不启用子智能体；仍遵守 main 直推、云端 Actions 和最新 artifact 复判链路。
- 保护工作区中用户未提交的 `RomeLegionsApp.xcodeproj/project.pbxproj`、xcuserdata 和 `md/unity分析/`，不得暂存、修改、回滚或清理。

## 背景

- v0.71 已将战斗页统一为青铜军令台，但地图中央仍主要依赖格子填色，战略地图与地貌之间缺少轻量制图参照；将领技能、军阶和战功信息在同一张卡内层级较平。
- 公开《大征服者：罗马》截图体现了地图主导、道路与海岸作为战略参照、将领身份和战斗收益快速可读的视觉方向。项目继续使用原创代码绘制，不引入原作素材。

## 目标

1. 在 `WarMapView` 纯表现层加入低对比度制图网格、经纬/标尺感和地图内框，让道路、海岸、城市节点和六边格拥有统一的战略底图层级。
2. 微调背景、六边格内高光/阴影和地貌材质，使平原、森林、丘陵、水域、道路、城市在深色战场中有更明确的材料分离，同时保留现有 overlay 颜色语义和静态采样覆盖。
3. 重构 `GeneralTraitCardView` 与紧凑版将领条的视觉层级：将领特性、技能状态、军阶/战功和技能目标使用青铜军令台 token 分组，继续只消费既有 ViewModel 派生数据，不新增规则。
4. 保持地图镜头、五种 display context、命令入口、15 张预览路径、44pt 命中区、无障碍文案和 `GameState`/AI 不变。

## 非目标与禁止项

- 不新增 `GameState`、Codable、AIIntent、存档字段、命令队列或新的将领规则。
- 不在 SwiftUI body 里复制路径、战斗、AI 或评分计算；地图制图层只绘制固定视觉参照。
- 不引入第三方框架、远程图片或原游戏素材；不修改用户保护文件。
- 本地不运行测试、build、typecheck、RenderBattlePreview、`Tools/verify_project.mjs`、解析脚本或 `git diff --check`。

## 实现步骤与关键文件

1. 在 `RomeLegionsApp/Views/BattleMapView.swift` 增加独立 `MapCartographyGridView`，由 `HexMetrics` 复用同一地图坐标；在地图底层叠加低透明经纬线、刻度/罗盘标记和内框，不抢地图命中。
2. 调整 `MapBackdropView`、`HexTileView` 的表现层颜色和内缘高光/阴影；不改变 terrain profile、海岸段、道路与 overlay 数据来源。
3. 在 `RomeLegionsApp/Views/BattlePanels.swift` 复用 `BattlePalette`，把将领卡头部、技能状态、战功进度与目标读板分成清楚的青铜/象牙/信号组；按钮 action 与 accessibility 保持原样。
4. 同步 `README.md`、`md/flow/flow.md`、`md/flow/flowchart.md`、`md/test/test.md`、`md/prompt/README.md` 和 `update_log.md`，写明真实架构及云端待验收状态。
