# v0.76.3 敌军作战计划青铜情报牌

## 背景

承接 v0.76.2。云端截图已确认地图主视觉和底部军令坞成立；敌军作战计划卡仍使用单色半透明底，和罗马战役的青铜/羊皮纸信息牌层级不一致。

## 目标

- 将 `AIOperationalPlanCardView` 改为青铜军令台渐变卡：保留计划类型色作为强调色，增加 raised panel、暗角和顶部信号线。
- 保持 `AIOperationalPlanSummary`、时间线步骤、AI 意图、路线和伤害数据完全不变。

## 非目标

不改变 AI 评分、GameState、命令执行、地图 overlay、存档、截图数量或第三方依赖；不运行本地测试或构建。

## 验收

仅通过 `main` 云端验证。Agent C 核对最新 commit 的 manifest、JUnit、主日志、RenderBattlePreview 十五张图和 Xcode build；确认敌军作战计划仍显示类型、来源、影响、热度与三步时间线。
