# v0.76.4 地图将领徽章特性图标

## 背景与目标

承接 v0.76.3。战斗页地图已有将领姓名徽章，但徽章只显示人物图标；本轮让地图空间层直接提示将领特性/技能类型，靠近罗马战棋的军团旗标信息密度。

## 实现

`CommanderTokenBadgeView` 新增可选 `GeneralTrait`，使用特性对应的 SF Symbol；无特性时保留人物图标回退。只改变地图徽章表现，不改变 GameState、AI、命令、技能预览或存档。

## 验收与限制

只在 `main` 提交并由 GitHub Actions 验证；本地不运行测试、构建、渲染、结构检查或 diff-check。Agent C 核对最新 manifest、JUnit、日志和十五张 PNG，确认将领徽章在地图与原有姓名、军团、血条层级共存。
