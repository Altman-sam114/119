# v0.74 战区雾边与地图材质复现

## 版本依据与背景

版本承接 v0.73。百度图片中的《大征服者：罗马》截图呈现浅色雾边包围地图、地图占据主视觉、圆形军团标记与金属信息牌分层。本轮只把这些视觉关系转译到原创 SwiftUI 底图。

## 目标

- 在 `WarMapView` 的底图与制图层之间加入 `MapFogOfWarEdgeView`，形成四边低对比雾边。
- 保持路线、海岸、单位、城市、叠层、HUD、镜头、44pt 命中区和将领读板可读，不改变任何规则或状态。
- 同步 CI_VERSION、README、flow、flowchart、test、prompt README 与 update_log。

## 非目标和禁止项

- 不复制、下载、嵌入百度或原作截图，不引入第三方框架。
- 不修改 `GameState`、AI、存档、命令入口、Render 的 15 张路径或用户保护文件。
- 本地不运行测试、build、Render、verify、解析命令或 `git diff --check`。

## 云端验收

- 只在 `main` 提交并推送；由 GitHub Actions 运行 Static、SwiftPM、Gameplay Smoke、RenderBattlePreview 和 Xcode build。
- Agent C 必须下载最新未加密 artifact，核对 branch、commitSha、runId、runAttempt，并逐图确认雾边低对比、地图主导和所有上下文无回归。
- 云端失败时追加修复 commit，不回滚、不沿用旧 artifact。
