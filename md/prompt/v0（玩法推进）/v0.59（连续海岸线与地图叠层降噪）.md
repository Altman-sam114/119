# v0.59 连续海岸线与地图叠层降噪

## 版本号与分配依据

- 版本号：v0.59。
- 依据：`md/prompt/v0（玩法推进）/` 当前最新为 v0.58（战略地图镜头与聚焦控制），本轮继续按玩法推进链路递增。

## 背景

对照《大征服者：罗马》参考截图与 v0.58 云端六图（run `30196901750`），当前战略地图与参考作的最大视觉差距是：

1. 水域和陆地按六边形逐格填色，水陆交界没有连续海岸线，地图呈"色块棋盘"而非"整片大陆 + 海域"的战略地图观感。
2. 默认渲染视角（热区/控区）下，`ThreatHeatTileOverlay` 与 `MapControlTileOverlay` 在大量地块上绘制高对比虚线描边和逐格图标，视觉噪声覆盖半张地图；参考作的态势信息以低对比色块和少量关键徽标呈现。
3. 每个六边形默认黑色描边偏重，叠加后强化了棋盘感。

## 目标

1. 水陆交界绘制连续海岸线带（沙色岸线 + 浅色浪缘），使海域读作整片海、陆地读作整片大陆。
2. 威胁热区、控区叠层降噪：低透明填充 + 细实线，热区图标只在热区中心格显示，不再逐格重复。
3. 默认格描边减淡，地形底色加入按坐标确定性的微量明度变化，增强手绘地图质感。
4. 云端 RenderBattlePreview 新增海岸线策略断言，异常抛出 `missingCoastlineStrategy`。

## 非目标

- 不修改 `GameState` 核心规则、AI、将领、存档或任何玩法数据。
- 不修改镜头（`MapViewportState`）、命令坞、抽屉、情报坞的行为与布局。
- 不改变可移动/可攻击/技能/选中/反制/目标线等交互叠层的显示逻辑。
- 不引入图片资源或第三方框架；全部用 SwiftUI 矢量绘制。

## 实现步骤

1. 在 `BattleMapView.swift` 新增纯值海岸线构建：
   - `struct CoastlineSegment`：包含水格位置、陆格位置、两中心几何中点与朝向角；
   - `func coastlineSegments(tiles:metrics:)`（或静态构建器 `CoastlineBuilder`）：对全部地块按中心距离阈值（约 `tileWidth * 0.95`）找出水-陆相邻对，每对产出一段海岸线；只依赖 `Tile` 与 `HexMetrics`，不读写任何状态。
   - 新增 `CoastlineLayerView`：在地貌层与路线层之间，按段绘制垂直于水陆连线的圆头短线（沙色主笔 + 更细浅色浪缘），随镜头统一变换。
2. `HexTileView` 降噪：
   - 默认描边由 `black.opacity(0.10)` 减至约 `0.05`、线宽收窄；选中/可攻击/可移动描边保持不变；
   - `tileColor` 按 `(x, y)` 确定性哈希加 ±3% 左右明度抖动（纯函数，不引入随机数）。
3. `ThreatHeatTileOverlay` 重构：低透明填充（约 0.12）+ 细实线（不再虚线、不再逐格 44pt 图标）；新增 `isZoneCenter` 参数，仅当 `tile.position == summary.targetPosition` 时绘制等级图标。`HexTileView` 传入该参数。
4. `MapControlTileOverlay` 降噪：填充与描边透明度进一步下调，虚线改细实线。
5. `Tools/RenderBattlePreview/main.swift`：
   - 渲染前断言：战役地图海岸线段非空；每段一端是水、一端是陆；深海格（如 `(1,6)`，六邻均为水）不产出海岸段；异常抛出 `missingCoastlineStrategy`（新增 error case）。
6. `Tools/verify_project.mjs`：battle token 列表追加 `CoastlineLayerView`、`coastlineSegments`、`isZoneCenter`。
7. `.github/workflows/ci-results.yml`：`CI_VERSION` 提升到 v0.59。
8. 文档：README 特性行、`md/flow/flow.md` 地图层描述、`md/test/test.md` v0.59 门禁段、`md/prompt/README.md` 最新提示词指针。

## 测试与 CI / main push 要求

- 云端-only：本地不运行任何测试、build、typecheck、RenderBattlePreview、结构检查或 `git diff --check`；只做读取、编辑、只读 `git status` / `git diff`、提交与 `git push origin main`。
- push 后由 GitHub Actions 完整跑结构检查、Swift Testing、Gameplay Smoke、RenderBattlePreview（含新增 `missingCoastlineStrategy` 断言与既有全部断言）、无签名 Xcode build。
- Agent C 下载最新 run 未加密结果包，核对 manifest/JUnit/日志，并目视复判六图：水陆交界出现连续海岸线、热区视角噪声显著下降、格描边减淡后地貌与路线仍清晰、无新增裁切/重叠/错位。

## 验收标准

1. 云端 run 全绿，manifest 与 `origin/main` 最新 commit 精确匹配。
2. 六图中水陆交界可见连续沙色海岸带；热区视角不再出现大面积高对比虚线；命令坞、情报坞、镜头工具、顶部战况不受影响。
3. `missingCoastlineStrategy` 断言存在且通过；既有 `missingStrategicMapMaterialCoverage` 等全部门禁不回退。

## 风险与禁止项

- 风险：像素采样对比度依赖既有余量；描边减淡后若材质对比不足会触发 `missingStrategicMapMaterialCoverage`——当前余量约 40 倍，风险低；若触发则退回加深地貌纹理层而不是放宽阈值。
- 禁止：把海岸线数据写入 `GameState` 或存档；禁止修改玩法规则与命令行为；禁止删除既有断言或降低阈值；禁止把本轮伪装成已本地验证。
